Stet

The system of record for AI agents.

Every model call and tool call your agent makes through Stet is written to a tamper-evident journal before the agent sees the result. A crashed run resumes without repeating finished work, and any run replays exactly, without calling the model.

See how Stet works Become a design partner

0.5, open source, is about to be released. Evidence for auditors and Stet Server are in design-partner preview for 0.6.

Crash points tested, each resumed exactly Every entry

Iris

A browser for the Mac, built on WebKit.

Spaces down the side, each with its own tabs and, if you like, its own profile. Chrome extensions, passwords in your Mac’s keychain, and ads and trackers blocked. The first time it opens, it brings over what you had in Arc, Dia, Chrome or Safari.
