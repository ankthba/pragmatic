The runtime is now called Stet, and Pragmatic now makes Iris.

Until today, Pragmatic was the name of both the company and its first product. The company keeps the name. The product is now called Stet, and Pragmatic Server is now Stet Server.

Stet is the proofreader’s mark for “let it stand”: leave the text as it was written. Nothing else about the product changes. 0.5 is still open source under Apache 2.0, Stet Server is still in design-partner preview for 0.6, and the names in code stay for now: you still import pragmatic, mark agents with @pragmatic.durable, and run pragmatic verify.

Pragmatic also now makes Iris, a browser for the Mac built on WebKit, the engine Safari uses. It has Spaces in a sidebar, runs Chrome extensions and keeps passwords in the Mac’s keychain, and the first time it opens it brings over what you had in Arc, Dia, Chrome or Safari. It is coming soon, free, for macOS 26 or later.

Aniketh Bandlamudi
