# Pragmatic website

The public website for Pragmatic, served by GitHub Pages at
https://aniketh.net/pragmatic/ (a project site under the aniketh.net
custom domain).

- `index.html` and the folders beside it are the pages.
- `pragmatic.css` and `pragmatic.js` are shared by every page.
- `wiki/index.html` is the encrypted engineering wiki. It is built from
  private sources that never enter this repository; only the encrypted
  page is published here.

Product source code lives at https://github.com/pragmaticco/pragmatic.
